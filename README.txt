RENEE'S BOUTIQUE - START FROM SCRATCH

This products.json removes all products from the website display.
It does not delete old image files stored in GitHub; it simply makes the website stop displaying the old products.

HOW TO USE:
1. Open your Renee-boutique GitHub repository.
2. Open products.json.
3. Click the pencil/Edit button.
4. Replace the contents with this products.json.
5. Commit the changes.
6. Wait a few minutes and refresh your website.
7. The old products/pictures will no longer appear.
8. Then add your new products and prices one by one.

IMPORTANT:
Do not delete index.html.
Do not change your website layout.
